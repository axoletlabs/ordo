# Reading fonts

The article reader ships two typefaces chosen for long-form reading
([nicoverbruggen/ebook-fonts](https://github.com/nicoverbruggen/ebook-fonts),
standardized builds for e-reading, v2026.08.05):

- **Libron** (serif) — Nico Verbruggen's reading refinement of Newsreader
  (Production Type). The reader's default typeface. `LICENSE-Libron.txt`.
- **NV Legible Next** (sans) — Nico's build of Atkinson Hyperlegible Next
  (Braille Institute), designed for maximum legibility. `LICENSE-NVLegibleNext.txt`.

Both are licensed under the SIL Open Font License 1.1; the bundled license
files name the original authors as that license requires. Font files are
renamed (Expo font keys) but are otherwise the unmodified release TTFs.
