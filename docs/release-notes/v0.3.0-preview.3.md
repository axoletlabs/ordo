### Easier reminders and reading

This Preview adds a clock for reminders and makes the reader and library easier to use.

#### New

- Set a custom reminder time with a clock picker.
- Spot unread bookmarks by the badge on their site icon.
- Copy your authenticator key, or enlarge its QR code when setting up sign-in.

#### Improved

- Reader controls open faster, and the Contents panel gives article sections more room.
- Browse Stable release notes alongside Preview history in the new release notes sheet.
- Menus, bookmark selection, and loading indicators respond more smoothly.

#### Fixed

- If a tag edit fails, the previous tags are restored.
- Touches no longer reach the screen behind an open dialog.
