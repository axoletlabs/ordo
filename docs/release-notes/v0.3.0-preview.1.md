### Quicker, steadier reading

This Preview makes large libraries and long articles easier to use, while making library changes more reliable.

#### Improved

- Large libraries scroll more smoothly, and long articles respond faster.
- The Contents panel takes less space and has a close button.
- Reminder dates are clearer, and sign-in code digits are easier to edit.
- App downloads are smaller.

#### Fixed

- Moving bookmarks and undoing deletion work more reliably, including after a restart.
- Android Back can cancel an incoming share.
- The Contents button no longer covers the end of an article.
