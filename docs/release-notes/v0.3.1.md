### More reliable folder deletion

Ordo 0.3.1 fixes how kept bookmarks appear when you delete a folder and makes release history easier to browse.

#### Improved

- **Release history** — Wider version buttons make release names easier to read.

#### Fixed

- Bookmarks selected to keep remain visible while Undo is available and return to the folder if you undo the deletion.
- The folder deletion screen refreshes its bookmark choices before confirming, so it doesn't use an outdated list.

#### Before you update

If you are updating from 0.1.0 on Android, uninstall it first. Your saved library stays on the server, but local settings and cached data are cleared.
