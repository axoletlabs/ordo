### More control over your library

This Preview lets you keep selected bookmarks when deleting a folder and makes small updates quieter.

#### New

- Choose which bookmarks to keep when deleting a folder.

#### Improved

- Small updates download quietly and take effect the next time you open the app.
- Release history shows clearer version names.
- Reader controls and menus respond more smoothly.

#### Fixed

- Sign-in and account settings handle more cases reliably.
